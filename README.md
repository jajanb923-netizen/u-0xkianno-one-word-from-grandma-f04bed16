One word from grandma about AI: **robit** — the typo she would actually
type for "robot". Warm, a little baffled, funny in a single word, and tied
straight to robots. `main.py` (Python 3.13 stdlib only, deterministic, no
network) writes that one word to `/output/entry.txt`.

## Run it

```sh
python3 main.py
```

Local run (writes to `./out/entry.txt` instead of `/output/entry.txt`):

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```
